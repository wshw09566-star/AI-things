# HOLLOW SURVEY — Pinned Milestone Rubric

## Judge configuration

- QA model: `vertex-gemini-3.5-flash`
- Reasoning effort: configured default
- Rule: QA runs sequentially after producing agents stop. QA never changes production code.
- Verdict format: per-item `PASS` or `FAIL`, followed by defects with severity, reproduction command, expected result, and actual result.
- Gate: both rubric verification and adversarial verification must pass. Any unexplained break is a milestone failure.

## Global gates for every milestone

1. Full committed test suite passes through `./tools/run.sh test`.
2. `./tools/doctor.sh` prints `DOCTOR OK` and exits 0.
3. Godot 4 API-drift lint is clean.
4. The milestone's deterministic headless playthrough passes.
5. `tests/fuzz/` is cumulative, runs in the full suite, and has not shrunk.
6. No `# TODO`, production `pass`, placeholder, or stub is presented as finished.
7. Save/load preserves deterministic behavior for all implemented state.
8. QA returns an overall `PASS` after the adversarial pass.

## M0 — Provision

- [ ] Repository is usable from a clean clone.
- [ ] Godot 4.7.1 stable Linux headless is installed at `/opt/godot` and version is asserted.
- [ ] GdUnit4 is vendored at a pinned revision and included by the suite.
- [ ] `tools/doctor.sh` validates dependencies, disk budget, repo state, Godot version, and API drift; success ends with exactly `DOCTOR OK`.
- [ ] API-drift lint rejects at minimum: `KinematicBody`, `KinematicBody2D`, `Spatial`, `Reference`, `PoolVector3Array`, `yield(`, `export(`, `onready var`, `.instance()`, `Directory.new()`, `File.new()`, legacy three-argument `connect`, and `get_tree().set_input_as_handled()`.
- [ ] `tools/run.sh` serializes Godot/test/capture invocations using a lock and assigns distinct displays by agent identity.
- [ ] One real GdUnit4 smoke test passes through `tools/run.sh`.
- [ ] `tests/fuzz/` and `tests/playthroughs/` are wired into the full suite.
- [ ] xvfb + Mesa llvmpipe captures a real 640×360 PNG generated by the Godot project.
- [ ] Capture is committed and validated as a non-empty 640×360 PNG.
- [ ] Repository remains below 500 MB and contains no downloaded game assets.

### M0 exact verification sequence

```bash
./tools/doctor.sh
./tools/run.sh test
./tools/run.sh capture --output artifacts/m0-smoke.png --width 640 --height 360
file artifacts/m0-smoke.png
git status --short
```

## Required M0 adversarial attempts

1. Concurrent test and capture requests: verify lock serialization and no cache corruption.
2. Stale lock after killed process: verify recovery without parallel Godot instances.
3. Deliberate Godot 3 identifier fixture: verify API-drift lint fails.
4. Missing/corrupt Godot binary: verify doctor fails closed with actionable output.
5. Headless execution with no display variables: verify logic tests still run.
6. Point-cap saturation, mid-action saves, erasure during traversal, act sequence breaks, and fixed-seed reload determinism are recorded as not-yet-applicable at M0 and become mandatory as soon as their systems exist.
